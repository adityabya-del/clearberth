# ClearBerth

A train seat availability checker for Indian Railways — search by route, date, class, and quota to see live berth availability across trains.

## About

ClearBerth is a mobile app that helps travelers quickly check seat availability without navigating IRCTC's booking flow. Users can search, compare classes, check PNR status, view live train running status, and jump straight to IRCTC to complete their booking.

This repository hosts the project's landing page.
